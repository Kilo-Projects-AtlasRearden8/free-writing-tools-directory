# Free Writing & Editing Tools

A no-account, no-affiliate directory of free word processors,
distraction-free editors, grammar help, name generators, and ebook
converters. Published by **Asdale Dynamics, LLC**.

Every tool listed is free to use and requires no account. Each entry
includes cost, platform, steps to get started, and the official link.
No affiliate links are used.

## Word Processors

### LibreOffice Writer
- **Cost:** Free
- **Platform:** Windows, macOS, Linux
- **Steps:** Download the installer from libreoffice.org, run it, open LibreOffice Writer, and start writing. Use File > Export as PDF to share.
- **Official link:** https://www.libreoffice.org/

### Apache OpenOffice Writer
- **Cost:** Free
- **Platform:** Windows, macOS, Linux
- **Steps:** Download from openoffice.org, install, launch OpenOffice, open Writer, and edit. Save as .odt or export as PDF.
- **Official link:** https://www.openoffice.org/

### ONLYOFFICE Desktop Editors
- **Cost:** Free
- **Platform:** Windows, macOS, Linux
- **Steps:** Download from onlyoffice.com, install, launch the Document editor, and edit files locally offline.
- **Official link:** https://www.onlyoffice.com/

## Distraction-Free Editors

### FocusWriter
- **Cost:** Free
- **Platform:** Windows, macOS, Linux
- **Steps:** Download from gottcode.org/focuswriter, install, open, and write full-screen with menus hidden at the screen edges.
- **Official link:** https://gottcode.org/focuswriter/

### WriteMonkey
- **Cost:** Free (donationware)
- **Platform:** Windows
- **Steps:** Download the portable ZIP from writemonkey.com, extract, run WriteMonkey.exe, choose your look, and write. Save as .txt or .md.
- **Official link:** https://writemonkey.com/

### Calmly Writer
- **Cost:** Free (web)
- **Platform:** Web
- **Steps:** Open calmlywriter.com, start typing, use the menu for formatting and word count, then save as .txt, .md, or HTML.
- **Official link:** https://calmlywriter.com/

## Grammar & Style Help

### Hemingway Editor (web)
- **Cost:** Free (web)
- **Platform:** Web
- **Steps:** Paste your text at hemingwayapp.com, review color-coded highlights, rewrite dense sentences, then copy the result back.
- **Official link:** https://www.hemingwayapp.com/

### LanguageTool
- **Cost:** Free
- **Platform:** Web, Windows, macOS, Linux
- **Steps:** Paste text at languagetool.org, select your language, review suggestions, and optionally install the free desktop app.
- **Official link:** https://languagetool.org/

### Slick Write
- **Cost:** Free
- **Platform:** Web
- **Steps:** Open slickwrite.com, paste your writing, click Proofread, and apply the suggestions you like.
- **Official link:** https://www.slickwrite.com/

## Name Generators

### Reedsy Character Name Generator
- **Cost:** Free
- **Platform:** Web
- **Steps:** Visit the Reedsy name generator, pick a category or origin filter, browse generated names, and save your favorites.
- **Official link:** https://blog.reedsy.com/character-name-generator/

### Fantasy Name Generators
- **Cost:** Free
- **Platform:** Web
- **Steps:** Go to fantasy-name-generators.com, choose a generator, click to generate names, and pick your favorite.
- **Official link:** https://www.fantasy-name-generators.com/

## Ebook Converters

### Calibre
- **Cost:** Free
- **Platform:** Windows, macOS, Linux
- **Steps:** Download from calibre-ebook.com, install, add your book, select it, and click Convert books to pick your output format.
- **Official link:** https://calibre-ebook.com/

### Online Convert (Ebook Converter)
- **Cost:** Free
- **Platform:** Web
- **Steps:** Go to online-convert.com, choose Ebook converter, upload your file, pick the target format, and download the result.
- **Official link:** https://www.online-convert.com/
